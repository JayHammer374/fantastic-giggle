# Brief del Proyecto: Generador Inteligente de Proyectos (PM & ISO)

## 🎯 Objetivo General
Desarrollar un agente/aplicación que genere propuestas y planes de proyectos completos y listos para presentación en Colombia. El sistema debe estructurar los planes bajo el ciclo PHVA (Planear, Hacer, Verificar, Actuar), integrar investigación de precios del mercado local, estimación de imprevistos (A.I.U.), análisis estadísticos (Pareto) y dar cumplimiento a estándares de gerencia y normativas ISO.

## 🛠️ Stack Tecnológico
- **Frontend:** HTML nativo, CSS (Tailwind CSS recomendado para agilidad) y JavaScript.
- **Entorno de Trabajo:** VS Code + Agente Cline para el desarrollo.
- **Herramientas de IA:** Conexión a modelos avanzados (OpenRouter/OpenAI/Gemini) mediante API keys optimizadas.

## 📋 Funcionalidades Clave (MVP)
- [ ] **Estructurador PHVA:** Plantilla automatizada para segmentar el proyecto en las 4 fases del ciclo de calidad.
- [ ] **Módulo ISO:** Checklists e integración de requisitos de normas ISO aplicables a la gestión documental y procesos.
- [ ] **Cotizador y Mercado Local:** Capacidad de estructurar presupuestos con datos reales de materiales y tarifas de Colombia.
- [ ] **Herramientas de Control:** Generación de matrices de priorización (Pareto) y asignación de recursos.
- [ ] **Módulo Legal y Financiero:** Inclusión de consideraciones legales en Colombia, cálculo de imprevistos y desperdicios.

## 🎨 Reglas de Diseño y Estilo
- **Estilo:** Profesional, limpio y corporativo (tableros de control scannables).
- **Enfoque:** Gratuidad y economía, priorizando herramientas eficientes y arquitecturas ligeras.
